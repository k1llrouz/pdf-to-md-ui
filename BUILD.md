# Сборка Windows-установщика

Важно: PyInstaller не умеет кросс-компиляцию. Windows-exe собирается **только
на Windows** — на macOS получится macOS-приложение. Вариант без своей машины:
GitHub Actions с раннером `windows-latest`.

## Быстрый путь: build.bat

На Windows достаточно дважды кликнуть [build.bat](build.bat) в папке проекта.
Скрипт сам делает всё, что описано ниже: заводит `.venv`, ставит зависимости,
собирает урезанную JRE через `jlink`, запускает PyInstaller и, если найдёт Inno
Setup, собирает установщик.

Что нужно поставить заранее:

| Нужно | Зачем | Если нет |
|---|---|---|
| [Python 3.10+](https://www.python.org/downloads/windows/) (галочка «Add python.exe to PATH») | обязателен | скрипт остановится |
| [JDK 17+](https://adoptium.net) | `jlink` для встроенной Java | соберётся без JRE, тогда Java 11+ нужна на машине пользователя |
| [Inno Setup](https://jrsoftware.org/isdl.php) | Setup.exe для раздачи | соберётся только папка `dist\PDF to Markdown\` |

Результат — `dist\PDF to Markdown\PDF to Markdown.exe`. Это onedir-сборка:
копировать нужно папку целиком, не один exe. JRE скрипт кладёт внутрь этой же
папки, так что скопированная папка работает сама по себе.

Дальше — то же самое руками, по шагам.

## 1. Окружение

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt pyinstaller
```

## 2. Урезанная JRE

Пакет `opendataloader-pdf` запускает Java 11+. Чтобы пользователю не пришлось
ставить её самому, кладём рядом собственную. Релизы собираются на
[Eclipse Temurin](https://adoptium.net) 25 — его и ставьте на машину сборки
(подойдёт любой JDK 17+):

```
jlink --add-modules java.base,java.desktop,java.logging,java.naming,java.xml,jdk.unsupported ^
      --strip-debug --no-header-files --no-man-pages --compress=zip-6 ^
      --output jre
```

Получается около 45 МБ. Набор модулей минимальный из рабочих: `java.desktop`
нужен для отрисовки страниц, `jdk.unsupported` — PDFBox. Если при
конвертации вылетит `NoClassDefFoundError`, добавьте нужный модуль или
соберите с `--add-modules ALL-MODULE-PATH` и урежьте потом. На JDK старше 21
вместо `--compress=zip-6` пишите `--compress=2`.

Приложение само найдёт эту папку — `_use_bundled_jre()` в
[gui.py](gui.py) выставляет `JAVA_HOME`, если рядом с exe лежит `jre\`.
Java, уже установленная у пользователя, имеет приоритет.

## 3. Сборка приложения

```
pyinstaller app.spec
```

Результат — `dist\PDF to Markdown\`. Проверьте, что внутри лежит jar из
`opendataloader_pdf`; если нет, значит `collect_all` его не подхватил —
добавьте путь к jar в `datas` вручную.

Затем скопируйте туда JRE из шага 2 — приложение ищет её рядом с exe, и
установщик берёт всё одной папкой:

```
robocopy jre "dist\PDF to Markdown\jre" /e
```

## 4. Установщик

Поставьте [Inno Setup](https://jrsoftware.org/isdl.php), затем:

```
iscc installer.iss
```

На выходе `Output\PDF-to-Markdown-Setup.exe`. Ставится в профиль
пользователя, без прав администратора и без запроса UAC. Галочка при
установке добавляет «Открыть в PDF → Markdown» в контекстное меню Проводника
для PDF и папок (ключи в `HKCU\Software\Classes`, удаляются вместе с
программой).

`installer.iss` хранится в UTF-8 с BOM: без него Inno Setup читает файл как
ANSI, и переведённые подписи пункта меню превращаются в кракозябры.

Иконку рисует `tools/make_icon.py` (нужен только PySide6):

```
set QT_QPA_PLATFORM=offscreen
python tools\make_icon.py
```

## Ожидаемые размеры

| Часть | Размер |
|---|---|
| Qt + Python | ~55 МБ |
| JRE после jlink | ~45 МБ |
| jar opendataloader | ~30 МБ |
| Установщик после lzma2 | ~50–60 МБ |

## Что проверить перед раздачей

Сначала автоматические тесты — они покрывают пачку с битым файлом, таймаут с
повтором без картинок, «Отмену», одноимённые файлы, запоминание настроек и
таблицы в выводе настоящего jar:

```
pip install -r requirements-dev.txt
python -m pytest tests
```

Тесты заодно проверяют, что заплатка скрытого текста из `patches/` подходит
к закреплённой версии opendataloader-pdf и что страница с тысячами линий
конвертируется в 128 МБ. После обновления пакета прочитайте
[patches/README.md](patches/README.md).

Руками остаётся то, что тестам недоступно:

- Запуск на чистой Windows без Python и без Java.
- PDF с кириллицей в имени файла и в пути.
- Путь с пробелами (`C:\Users\Иван Петров\Мои файлы`).
- «Отмена» на длинном файле: окно освобождается сразу, java.exe исчезает из
  диспетчера задач.
- PDF, перетащенный на значок exe, сразу появляется в списке файлов.
- Значок программы — на exe, в заголовке окна, на панели задач, у
  установщика и в «Установленных приложениях».
- Правый клик по нескольким PDF в Проводнике → «Открыть в PDF → Markdown»:
  открывается одно окно со всеми файлами. Повтор, пока окно открыто, —
  файлы добавляются в то же окно, и оно выходит на передний план.
- После удаления программы пункт в контекстном меню пропадает.
- Окно, закрытое в другом месте и другого размера, открывается так же.
- «Настройки → Тема»: светлая и тёмная меняют и заголовок окна, и заголовки
  диалогов — в том числе когда в Windows выбрана противоположная тема.
- «Справка → Проверить обновления» отвечает «У вас последняя версия» (значит,
  HTTPS работает в сборке). После выхода следующего релиза старая версия
  показывает в углу окна «↑ Доступна версия …».
- Нажатие на «↑ Доступна версия …» в установленной программе: вопрос, окно
  загрузки с полосой и «Отмена», затем программа закрывается, установщик
  показывает только ход установки и открывает программу снова — в той же
  папке, с теми же настройками и пунктом контекстного меню. Журнал
  установщика — `%TEMP%\pdf-to-md-update-*\install.log`. Запущенная из
  папки `dist` или из исходников программа по нажатию только открывает
  страницу релиза.
- «Настройки → Язык»: окно пересобирается на выбранном языке, список
  файлов и настройки остаются. На самом длинном языке (сейчас польском) при
  минимальной ширине окна с открытыми «Дополнительно» и «Избранными папками»
  нет горизонтальной прокрутки. (Тестами это не проверить: в режиме без
  экрана Qt подставляет другие, более широкие шрифты.)
- F1 открывает инструкцию без интернета (значит, `docs/guide.*.md` попали в
  сборку).
- Наведение на любой «?» сразу показывает подсказку с переносами строк.
- Установщик открывается на языке Windows и показывает лицензию GPL.
- Первая строка журнала — «PDF → Markdown <версия> · opendataloader-pdf
  <версия>», без `?` (значит, метаданные пакета попали в сборку).
- «Справка → О программе» показывает ту же версию, что и метка релиза, а
  кнопки в окнах-вопросах — на языке программы («Да / Нет», а не «Yes / No»).
- С галочкой «Дополнительно → Отбрасывать скрытый текст» журнал пишет
  «скрытый текст: отбрасывается» (значит, `patches/hidden-text` попала в
  сборку и подходит к jar).
- Настоящий даташит с графиками (например, TI tps7a02) конвертируется за
  секунды, без `OutOfMemoryError` в журнале.
