# Инструкция: PDF → Markdown

Программа превращает PDF — особенно даташиты и техническую документацию — в
Markdown, JSON, HTML или простой текст. Всё, что нужно для работы, включая
Java, идёт в комплекте.

## Быстрый старт

1. Добавьте PDF или целую папку.
2. Отметьте нужные форматы.
3. Нажмите **Конвертировать**.

Результат по умолчанию ложится в папку `output` рядом с исходными файлами.

## Добавить файлы

- Перетащите PDF или папку в окно программы.
- Или нажмите **Добавить файлы** / **Добавить папку** (Ctrl+O / Ctrl+Shift+O).
- Или перетащите PDF прямо на значок программы.
- Или щёлкните по PDF или папке правой кнопкой в Проводнике и выберите
  **Открыть в PDF → Markdown**. В Windows 11 этот пункт находится в разделе
  **Показать дополнительные параметры**.

Если программа уже открыта, новые файлы добавляются в то же окно.

**Убрать лишний файл:** выделите его в списке и нажмите **Убрать** или клавишу
**Delete**; можно выделить несколько с Ctrl или Shift. То же есть в меню по
правому клику. **Очистить** убирает весь список. С диска ничего не удаляется.

## Форматы вывода

| Формат | Что получится |
|---|---|
| Markdown | Текст с заголовками и таблицами. Таблицы записываются в HTML, поэтому объединённые ячейки не разваливаются. |
| JSON | Структура документа для программ: блоки, координаты, типы. |
| HTML | Страница для браузера. |
| Текст | Только текст, без разметки. |
| Tagged PDF | Исходный PDF с тегами структуры — для экранного чтения и других программ. |
| PDF с разметкой | Исходный PDF, поверх которого нарисовано всё распознанное. Помогает понять, почему таблица вышла не так. |

Можно отметить несколько форматов сразу.

## Опции

- **Картинки** — **Отдельные файлы**, **Внутри документа** (прямо в .md,
  один большой файл) или **Не сохранять**. Картинки — самая медленная часть
  работы.
- **Разрешение** — чёткость картинок. Для графиков обычно хватает 96 DPI.
- **Страницы** — например `1-12` или `1,3,5-7`. Пусто — все страницы.
- **Таймаут на файл** — если файл не уложился, он пробуется ещё раз без
  картинок.
- **Разделители страниц** — строка `---- page 3 ----` между страницами;
  снимите галочку, если нужен сплошной текст.
- **Убирать мусор от графиков** — графики, чертежи и блок-схемы часто
  превращаются в огромные таблицы из пустых ячеек. Вместо каждой такой
  таблицы остаётся строка «[Figure omitted, page N]» с подписью рисунка
  (всегда по-английски, как и сами даташиты);
  сам рисунок смотрите в PDF. То же со схемами и временными диаграммами,
  которые выходят длинной вереницей отдельных подписей («IO21», «GND»,
  «R2 100R», цифры шкал). В начало файла тогда добавляется строка для
  нейросети: рисунки убраны, и нужный она может попросить у вас скриншотом
  страницы. Включено по умолчанию.
- **Таблицы в чистом Markdown** — таблицы разметкой Markdown | через |
  черту | вместо HTML: файл примерно на четверть короче, для нейросети — на
  треть меньше токенов. Вся обработка делается до этого, поэтому MIN, TYP и
  MAX остаются в своих столбцах. Остальные места объединённой ячейки
  остаются пустыми. По умолчанию включено.

Возле каждой настройки есть значок **?** — наведите на него мышь, и появится
подробное объяснение. Кнопка **Сбросить** возвращает стандартные значения:
одна — для форматов и опций, другая — внутри **Дополнительно**.

## Дополнительно

Нажмите **Дополнительно**, чтобы открыть редкие настройки: порядок чтения,
способ поиска таблиц, формат картинок, пароль PDF и другие. Обычно
трогать их не нужно — объяснение каждой под значком **?**.

**Отбрасывать скрытый текст** — для результата, который отдают нейросети:
выбрасывает текст, которого не видно на странице (невидимый, белый на белом,
микроскопический, за краем страницы). Работает примерно вдвое медленнее, и
вместе с ним пропадают тонкие знаки — плюс, минус, равно: «var1 + var2» в
формуле превращается в «var1 var2». Не включайте для документов с формулами
или кодом. По умолчанию выключено.

Пароль для зашифрованных PDF нигде не сохраняется. Кнопка с глазом в поле
пароля показывает введённое.

## Куда сохранить

- Пустое поле — результат ложится в папку `output` рядом с исходными файлами.
- **Обзор…** — выбрать другую папку. Она запоминается до следующего раза.
- Крестик в поле — вернуться к варианту «рядом с исходными».

**Избранные папки** — до 5 папок, между которыми можно переключаться одним
кликом. Откройте их кнопкой под полем, выберите папку через **Обзор…** и
нажмите **Добавить текущую папку**. Крестик справа убирает папку из
избранного (сама папка на диске остаётся).

## После конвертации

- У каждого файла в списке появляется значок:
  зелёная галочка — готово; жёлтый «!» — сконвертирован без картинок (не
  уложился во время); красный крестик — не получилось.
- Двойной клик по файлу открывает результат.
- **Открыть папку результата** — открыть папку в Проводнике.
- Если что-то пошло не так, рядом со строкой состояния появляется ссылка
  **Подробнее** — она открывает журнал с деталями. Журнал можно открыть и
  всегда: **Настройки → Показывать журнал** (Ctrl+L).

## Что программа исправляет сама

- **Нечитаемые шрифты.** В некоторых PDF (Infineon, схемы выводов и подписи
  графиков TI, чертежи Microchip) буквы шрифта не подписаны, и вместо текста получались
  знаки «?». Программа восстанавливает их перед конвертацией — исходный файл
  не меняется.
- **Пропавшие страницы.** Маленькая картинка, вставленная прямо в текст
  страницы, могла заставить конвертер пропустить всё, что идёт после неё.
  Такие картинки сначала выносятся отдельно; страница выглядит так же.
- **Слипшиеся MIN/TYP/MAX.** В таблицах TI и ADI, где между столбцами MIN,
  TYP и MAX нет линий, числа раскладываются обратно по своим столбцам. Если
  по расположению на странице нельзя однозначно понять, где какое число,
  ячейка остаётся как была — растянутой на все три столбца.
- **Лишние картинки.** Одинаковые картинки сводятся в один файл; картинка,
  повторяющаяся на многих страницах (логотип, обрывок рамки), убирается из
  текста; файлы, на которые ничего не ссылается, удаляются.
- **Знаки < > &.** Конвертер записывает `<`, `>` и `&` как `&lt;`, `&gt;`
  и `&amp;`. Программа возвращает их там, где их нельзя принять за разметку:
  в коде получается `x >> 3`, а не `x &gt;&gt; 3`.

## Советы для даташитов

- Возьмите только нужные страницы — описание и таблицы параметров, например
  `1-12`, — и пропустите десятки страниц графиков.
- Долго? Поставьте **Разрешение** 96 DPI или **Картинки → Не сохранять**.
- Таблица вышла кривой? Отметьте формат **PDF с разметкой**, чтобы увидеть,
  что нашёл конвертер, и попробуйте **Дополнительно → Таблицы: по кластерам**.

## Настройки

- **Настройки → Язык** — язык программы.
- **Настройки → Тема** — светлая, тёмная или как в Windows.
- **Настройки → Проверять обновления при запуске** — при запуске программа
  спрашивает у GitHub, нет ли новой версии, и показывает ссылку в углу окна.
  Нажмите на неё, чтобы обновиться: программа скачает новую версию,
  закроется, установит её и откроется снова — настройки сохранятся. Если
  что-то пойдёт не так, вместо этого откроется страница загрузки. Версия
  2.1.0 и более ранние только открывают страницу: следующую версию нужно
  один раз скачать и установить вручную, а дальше обновление — одним
  нажатием. Проверить вручную: **Справка → Проверить обновления**.
- **Настройки → Сбросить настройки** — вернуть всё как после установки.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+O | Добавить файлы |
| Ctrl+Shift+O | Добавить папку |
| Delete | Убрать выделенные файлы из списка |
| Ctrl+Enter | Конвертировать |
| Esc | Остановить |
| Ctrl+L | Показать или скрыть журнал |
| F1 | Эта инструкция |
| Ctrl+Q | Выход |

## Если что-то не работает

- **Windows пишет, что защитила компьютер**, при установке: нажмите
  **Подробнее → Выполнить в любом случае**. Установщик не подписан цифровой
  подписью, это ожидаемо.
- **Файл не сконвертировался** — нажмите **Подробнее** под списком или
  откройте журнал. Битый или защищённый паролем PDF не мешает остальным
  файлам.
- **Нашли ошибку** — **Справка → Сообщить о проблеме**.
